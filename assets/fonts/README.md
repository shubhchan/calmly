# Fonts Directory

## Oddly Calming Font (`OddlyCalming.ttf`)
This file is currently pre-loaded with a Patrick Hand handwritten fallback. 

When you download **Oddly Calming** from Envato Elements (`https://elements.envato.com/oddly-calming-JLQMQVL`):
1. Extract the downloaded zip file.
2. Copy `Oddly Calming.otf` or `Oddly Calming.ttf`.
3. Rename it to `OddlyCalming.ttf` and replace this file (`assets/fonts/OddlyCalming.ttf`).
4. The app will immediately use the official Envato font!
